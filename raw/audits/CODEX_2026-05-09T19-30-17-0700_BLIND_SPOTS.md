# Blind Spots
Model: CODEX
Timestamp: 2026-05-09T19-30-17-0700

## Strategic Blind Spots
1. The system is optimizing for "agentic completeness" more than traffic or revenue completeness.
2. The business has a real niche edge, but the operating layer is spending too much energy proving it is intelligent instead of just being effective.
3. There is no hard operating principle that says "do not automate what you cannot measure."

## SEO Blind Spots
1. Canonicalized intent overlap between `/office-chairs-for-tall-people/` and `/best-office-chairs/` is still unresolved.
2. The noindex author page is still present in the sitemap.
3. Visible freshness and hidden freshness signals are misaligned across multiple pages.
4. `size-guide` exists without meaningful internal graph support.

## Affiliate Monetization Blind Spots
1. There is no outbound affiliate event tracking layer.
2. There is no page-to-revenue attribution in the repo.
3. There is no CTA experiment framework.
4. The site knows where links exist. It does not know which link placements work.

## Agent Logic Blind Spots
1. Autonomous editors are trusted more than the validation stack deserves.
2. The system uses regex and heuristics where semantic certainty is required.
3. A broken or polluted intelligence layer can still produce authoritative-looking plans.

## Automation Blind Spots
1. Monday mixes data collection and code editing.
2. Thursday and Friday still assume LLM output can safely land in production-oriented branches.
3. Force-push behavior means staging is not a reliable review environment.
4. There is no concurrency or locking model for wiki and report writes.

## Data Analysis Blind Spots
1. Hard row limits make the system non-scalable as search data grows.
2. Query semantics are not checked deeply enough.
3. Trend and device intelligence are described in docs more strongly than they exist in actual current data.

## Content Quality Blind Spots
1. Structure is over-validated. substance is under-validated.
2. First-person constraints are only partially enforced.
3. "Research-based" can still drift into synthetic confidence if chair claims are not sourced tightly.

## Technical SEO Blind Spots
1. Sitemap logic is manual and already missing at least one page `lastmod`.
2. Relative canonical output is still live on the author page.
3. Indexation intent and sitemap intent are not centrally verified.

## Repo Maintenance Blind Spots
1. There is no real test suite.
2. There are too many operational docs with different freshness levels.
3. The nested repo root inside a workspace root is easy for agents to misuse.

## Deployment Blind Spots
1. The deployment pipeline assumes branch choreography will remain understandable under more change volume.
2. There is no clean preview / approval environment modeled in-repo.
3. Main can receive automation-driven changes earlier in the week than the nominal final verification gate.

## Scaling Blind Spots
1. The current GSC pull design will lose fidelity as page and query counts grow.
2. The current wiki concept sprawl will become harder for agents to use as it expands.
3. The competitor system will not scale beyond a handful of manually chosen URLs.

## Cost / Time Blind Spots
1. Anthropic is being used for tasks that should be deterministic.
2. Several workflows rewrite strategy and audit narratives weekly, but not all of that narrative creates leverage.
3. The system produces a lot of motion artifacts: plans, logs, digests, weekly summaries, concept pages.

## Overengineering
- Multiple scoring layers without clean raw data.
- More concept pages than decision-critical datasets.
- Auto-fix loops before robust preconditions and rollback design.

## Underengineering
- URL normalization
- business analytics
- approval workflow
- tests
- truth-source hygiene

## Fake Precision
- `steelcase knee brace review` being ranked as a top chair-review opportunity
- null device data wrapped in a system that claims device intelligence
- stale raw GSC inputs driving fresh-looking analysis outputs

## Places Where Agents Pretend To Be Smarter Than They Are
- competitor monitor
- gsc-analyze scoring
- content quality gate
- regex-based voice safety

## Places With No Real Feedback Loop
- outbound affiliate click performance
- whether title/meta rewrites actually changed CTR by query family
- whether internal link changes changed rankings
- whether AI-overview-oriented formatting improved post-AIO click capture

## Motion Without Progress
- weekly plan generation when data freshness is questionable
- expanding intelligence pages while raw inputs remain capped and dirty
- maintaining many narrative docs instead of one strong operating dashboard
