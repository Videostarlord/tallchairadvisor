## High Priority

### 1. Trailing-slash URL split — 4 page pairs indexed twice by Google
GSC shows non-canonical (no-trailing-slash) URLs accumulating impressions separately from the canonical versions. Google has not fully consolidated these, splitting ranking signals:

| Non-canonical (no slash) | Impr | Canonical (slash) | Impr | Combined |
|---|---|---|---|---|
| /review/gesture | 256 | /review/gesture/ | 49 | **305** |
| /aeron-vs-gesture | 111 | /aeron-vs-gesture/ | 2 | **113** |
| /office-chairs-for-tall-people | 17 | /office-chairs-for-tall-people/ | 65 | **82** |
| /back-pain-spine-height | 7 | /back-pain-spine-height/ | 10 | **17** |

The no-slash version of `/review/gesture` is actually outranking the canonical — Google has absorbed 256 impressions to the wrong URL. This suggests external links or redirects are failing somewhere for this page.

**Fix:** Ensure 301 redirect from no-slash → slash is working site-wide (verify Cloudflare redirect rules). Then submit canonical URLs in GSC URL inspection to force recrawl.

### 2. Article schemas missing `author.@id` (9 pages)
These pages have Article schema but no author @id, breaking E-E-A-T attribution:

| Page | wordCount | author.@id |
|---|---|---|
| /office-chairs-for-tall-people/ | 2354 | NO_ID |
| /chairs/herman-miller-aeron/tall-people/ | 1898 | NO_ID |
| /chairs/steelcase-gesture/seat-depth/ | 1503 | NO_ID |
| /chairs/steelcase-gesture/tall-people/ | 1830 | NO_ID |
| /chairs/steelcase-leap-plus/tall-people/ | 1919 | NO_ID |
| /chairs/herman-miller-aeron/seat-height/ | 1158 | NO_ID |
| /chairs/steelcase-gesture/seat-height/ | 1557 | NO_ID |
| /chairs/steelcase-gesture/weight-limit/ | 1254 | NO_ID |
| /chairs/steelcase-leap-plus/seat-height/ | 1256 | NO_ID |

**Fix:** Add to each Article schema:
```json
"author": {
  "@type": "Person",
  "@id": "https://tallchairadvisor.com/author/jackson-christopher/#person",
  "name": "Jackson Christopher",
  "url": "https://tallchairadvisor.com/author/jackson-christopher/"
}
```
