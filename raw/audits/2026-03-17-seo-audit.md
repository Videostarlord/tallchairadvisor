## Issues by Priority

### HIGH

**H1 — 308 vs 301 redirects on no-slash URLs**
23 of 25 no-slash URL variants return HTTP 308 (Cloudflare default) rather than 301. Google passes PageRank through both, but 301 is the correct signal for canonical consolidation and what GSC expects.

Fix via Cloudflare dashboard → Rules → Redirect Rules (not Page Rules — deprecated):
- Match: `not ends_with(http.request.uri.path, "/") AND not starts_with(http.request.uri.path, "/cdn-cgi") AND not http.request.uri.path contains "."`
- Action: Dynamic redirect → 301 → `concat("https://tallchairadvisor.com", http.request.uri.path, "/")`

This replaces all individual `_redirects` no-slash lines with one universal rule.

**H2 — Thin content: /chairs/steelcase-leap-plus/ (~908 words)**
Confirmed thin. Missing:
- No "Leap Plus vs standard Leap V2" comparison (core buyer confusion point)
- No first-person testing note from Jackson
- No seat adjustment guide
- Generic verdict copy

Target: 1,100–1,200 words. Add 300–400 word "Leap Plus vs Leap V2" section + Jackson's personal setup notes.

**H3 — Review pages missing aggregateRating schema (blocks star rich results)**
`/review/gesture/`, `/review/leap-plus/`, `/review/aeron-size-c/` have Product schema but no `aggregateRating`. Stars in SERP = proven CTR boost. Critical for `/review/gesture/` at pos 10.39 with 256 impressions and 0.39% CTR.

Add to each Product schema:
```json
"aggregateRating": {
  "@type": "AggregateRating",
  "ratingValue": "4.5",
  "reviewCount": "1",
  "bestRating": "5",
  "worstRating": "1"
}
```
